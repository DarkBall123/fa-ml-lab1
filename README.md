Группа ПМ23-2.** Реальный API-эксперимент от 17.09.2026 по теме ВКР «Разработка системы компьютерного зрения для контроля качества сварных швов на основе архитектуры Vision Transformer (ViT) и методов Few-Shot Learning».

Сравниваются семь моделей: GPT-4.1 mini, GPT-4.1 nano, Qwen3 VL 8B, Qwen3 VL 32B, Qwen3 VL 30B A3B Instruct, Mistral Small 3.2 24B Instruct и Amazon Nova Lite в zero-shot и four-shot. Это визуальное in-context learning без обновления весов. ViT не обучался.

## Быстрая проверка без API и расходов

Python 3.12:

```sh
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python src/analyze.py
```

Скрипт проверит согласованность ответов и manifest, отсутствие пересечения групп, пересчитает метрики, 95% кластерные bootstrap-интервалы и список ошибок. Исходные ответы находятся в `results/predictions.jsonl`; результаты — `results/metrics.csv`, `results/summary.json`, `results/totals.json`.

## Данные

Официальный источник: https://github.com/stefyste/RIAWELC, commit `d53d3daf28ed3901f9db89764c030d19ced7696d`. Авторы: Benito Totino, Fanny Spagnolo, Stefania Perri. DOI: https://doi.org/10.53375/ijecer.2023.320.

README первоисточника говорит о свободном выпуске, но не содержит отдельной явной лицензии. Полный набор изображений не распространяется в этом репозитории. Отчет содержит отдельные иллюстрации из эксперимента. Для загрузки оригинальных 19 частей RAR (около 491 МБ) нужен установленный `unrar`:

```sh
python src/download_data.py
python src/prepare_data.py data/images
```

Каждый архив проверяется по размеру и Git blob SHA-1. Аудит изображений использует SHA-256 файлов и пикселей. Команда подготовки заново формирует те же manifest при неизменных данных, seed и версиях зависимостей; она перезапишет локальные manifest и audit.

Исходный набор содержит 24 407 PNG, фактически 227×227, L; README указывает 224×224. После удаления точных повторов остаётся 21 893 изображения. Между исходными частями обнаружены 2 465 общих групп пиксельных хешей. Использовано новое разделение по 29 префиксам имён до `_Img`, а не официальный split. Идентичность физического сварного соединения по этим префиксам не подтверждена.

Папки сопоставлены с классами по численности из публикации и визуальному просмотру: `Difetto1=CR`, `Difetto2=PO`, `Difetto4=LP`, `NoDifetto=ND`. Это правило явно зафиксировано в коде и аудите.

Фиксированные части: support/train 4, validation 16, comparison/test 80, application 160. В каждой классы сбалансированы. Между выбранными объектами исключены пары с dHash Hamming distance ≤4. dHash не доказывает отсутствие всех семантически близких изображений. Оставшиеся изображения не используются для инференса.

## Повторение API-эксперимента

Повторный запуск расходует средства OpenRouter. Ключ передаётся только через переменную окружения; `.env.example` содержит лишь шаблон. Не добавляйте ключ в Git.

```sh
read -s OPENROUTER_API_KEY
export OPENROUTER_API_KEY
python src/experiment.py data/images --stage validation
python src/experiment.py data/images --stage test
python src/experiment.py data/images --stage application
python src/analyze.py
unset OPENROUTER_API_KEY
```

В репозитории уже есть выполненный эксперимент. Скрипт **пропускает записанные результаты**; команды выше не повторяют имеющиеся запросы. Для нового независимого запуска предварительно скопируйте исходный репозиторий и переместите `results/predictions.jsonl` за пределы `results/`. Не смешивайте разные запуски в одном файле. Рекомендуется сохранить исходные результаты и исходный Git commit.

Параметры зафиксированы в `protocol.json`. Максимальный локальный бюджет — $0.85, резервная маршрутизация отключена. Для HTTP 429/502/503 допускаются три повторные попытки. Ошибки авторизации требуют остановки и исправления ключа. Поддержка `usage.cost` зависит от провайдера; локальный guard не является заменой лимиту ключа в OpenRouter. При прерывании запроса возможны расходы, не попавшие в локальный журнал.

Выбор победителя: среди **four-shot** моделей с invalid rate ≤5% максимизируется Macro-F1 comparison; при равенстве минимизируются пропуски дефектов и стоимость. Application не открывается до выбора и используется для подтверждающей оценки. Поэтому comparison — выборка отбора, а не окончательная несмещённая оценка победителя. Zero-shot выступает контрольным режимом.

## Метрики и оговорки

- Macro-F1: среднее F1 четырёх фиксированных классов. Невалидные ответы считаются ошибками.
- Пропуск дефектов: `true ∈ {CR, LP, PO}, predicted = ND` / все дефектные объекты.
- Цена: поле `usage.cost`, USD; на 1000 объектов — линейная экстраполяция.
- Задержка: время последней попытки HTTP-запроса; не полное время обработки с backoff. Исходная параллельность 8, после ограничений 4; для расширения до семи моделей использовано 12, поэтому это наблюдение API, а не строгий сравнительный бенчмарк скорости.
- Bootstrap: 2000 выборок с возвращением по группам источников; учитываются повторы с наличием всех четырёх классов. Интервалы ориентировочные из-за малого числа групп и выбора модели.
- Один support-набор, без обучения ViT, локализации дефектов или внешнего производственного теста. Новый application-срез принадлежит тому же RIAWELC.

На предварительной проверке Gemini Flash Lite отвечал HTTP 429 и заменён до окончательного сравнения. Временные неуспешные запросы и ошибки запуска сохранены в `excluded_provider_attempts.jsonl`; повторы новых запросов — внутри `retry_attempts`. Успешные ответы не заменялись по признаку качества. Все семь итоговых моделей оценены на одних объектах и с одним промптом.

## Состав

- `src/prepare_data.py` — полный аудит и формирование выборок.
- `src/download_data.py` — скачивание зафиксированных архивов.
- `src/experiment.py` — изображения, промпт, API, журнал и выбор модели.
- `src/analyze.py` — автономный пересчёт метрик и проверка целостности.
- `manifests/full_inventory.csv` — все 24 407 файлов и хеши.
- `manifests/experiment.csv`, `source_group_split.json` — неизменные части.
- `results/` — измеренные результаты, ошибки, параметры и каталог моделей.
- `report/` — итоговый отчёт Word.

Удалённый origin: https://github.com/DarkBall123/fa-ml-lab1.git.

Матрица десяти научных источников: `results/literature_matrix.csv`. Четыре модели добавлены после первого сравнения трех моделей; данные и промпт сохранены. Дополнительная выборка уже использовалась для GPT-4.1 mini. Новый выбор победителя производится только по comparison.

Amazon Nova Lite нарушает формат JSON из-за Markdown-обертки. Основные метрики используют строгий парсер. `normalized_diagnostic.json` содержит отдельную диагностику после удаления только внешней обертки для всех моделей; эти метрики не используются при выборе победителя.

Групповой эксперимент содержит 1504 результата: 224 validation, 1120 comparison и 160 application. Победитель после расширения сохранился (GPT-4.1 mini); его 160 ответов не запрашивались заново. Неформатные ответы Nova Lite сохранены, а диагностика после снятия Markdown не влияет на выбор модели.
